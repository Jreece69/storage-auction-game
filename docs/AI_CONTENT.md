# AI-generated content

Steam's content survey asks whether a game contains AI-generated content. This
file lists everything in the project that was made with AI tools, so Jack can
answer accurately. Update it whenever AI-made content is added, changed or
replaced.

Valve's form changes over time, so read its current wording when filling it
in. This list errs on the side of including everything.

## Made with AI during development (ships in the game)

| Content | Where | Tool | Notes |
|---|---|---|---|
| Game code | `game/scripts/`, `game/scenes/` | Claude Code (Anthropic) | Written from Jack's plan; checked by the test suite |
| UI text: menu labels and tagline | `game/data/translations/strings.csv` | Claude Code | Placeholder copy |
| Placeholder app icon | `game/icon.svg` | Claude Code | Hand-written SVG; to be replaced before launch |
| Placeholder UI theme | `game/assets/ui/theme.tres` | Claude Code | Default font size only |

## Generated by AI while the game runs

None, and none is planned.
